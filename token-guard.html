Automatic checks stop an AI assistant from using more than the work needs. Written rules did not hold. The AI agreed, then broke them an hour later. Each message is checked, then every step. Every block says the fix. 482 of 662 AI helpers ran as the heavy default type. Now blocked. Its first step takes 53.8k tokens. Lighter types, 16k to 20k. So the AI corrects itself. What it blocks

  • Helpers with no model named, which default to the most expensive one.
  • The heavy default helper. Nine lean helper types replace it.
  • Whole large files and full-size screenshots, which get re-read on every later step.
  • Chats that have grown too long and aren’t saving their progress.

Decisions I made

  • Enforce in code, not in the prompt. An instruction is a suggestion; a blocked step is a fact.
  • Check every step, not every message. Most waste happens while nobody is typing.
  • A long chat always ends in a clean handoff. It gets a warning, then a ready-made start for a fresh chat.
  • Fail open. If a check breaks, the step runs. A broken guard never stops good work.

How it was tested

  • Each check targets a leak found in real logs, and each one shrank the following week: Finding where my AI spending went.
  • 15 sample cases cover what each check allows and blocks.
