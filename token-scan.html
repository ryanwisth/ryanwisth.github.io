Problem
Every AI call costs tokens, the units AI use is billed in. The usage meter shows a total, not a cause. When a week’s allowance ran out early, I needed to know what used it up.
Result
Six scans turned a bare total on the meter into causes I could fix. 482 of 662 AI helpers ran as the heavy default type: 53.8k tokens in the first step, against 16k to 20k for lighter types. And 39% of cache reads (the AI re-reading text it saved earlier) came during long stretches with nobody typing, which a check on each message never saw. Each finding became a rule in my spending guard.

The problem

Every AI call’s tokens are already written to log files on my computer. But nothing added them up. Without a root cause, every fix was a guess.

Decisions I made

  • One comparable number. Each AI call gets one number, weighted by the price list, so cheap kinds of usage and expensive kinds land on the same scale. It is a ruler for comparing, not a bill.
  • Count each call once. One reply can fill several log lines, so each reply is counted once, by its ID.
  • One question per script. Six short scripts each print one table: totals, heavy results and images, why saved text had to be stored again, kinds of chat, re-reading of notes, and usage by model. Each answer can be checked on its own.
  • Read-only and local. No extra software to install, and nothing leaves the computer.
  • Guesses written down. Where a script has to guess, the rule is written down and its numbers can be changed, so every figure can be traced back to its rule.

How it was tested

  • Used for a real weekly spending review in November 2026, then kept as tools to reuse.
  • The findings became rules in claude-code-token-guard, aimed at the heavy helper type behind 482 of 662 helpers and the unattended stretches behind 39% of cache reads.
  • Each new rule was checked against the next week’s scan, so the same scripts that found a leak showed it was closed.

Limits

  • Reads Claude Code’s own log format, which can change with new versions.
  • Free to reuse (MIT license); not made or endorsed by Anthropic, the maker of Claude.
