Read the script

Six small scripts read an AI assistant’s logs, and show where the usage went. The usage meter shows a total, not a cause. A week’s allowance ran out early. The AI’s own logs are read. Each script answers one question, in a simple table. 482 of 662 AI helpers ran as the heavy default type. Its first step took 53.8k tokens: up to 3.4 times the cost, before any work. Used for a real weekly spending review in November 2026. Each finding became a rule. Details and code are below.

The problem

Every AI call’s tokens are already written to log files on the computer, but nothing added them up. Without a root cause, every fix is a guess.

Decisions I made

  • One comparable number. Each call is weighted by the price list, so cheap and expensive usage land on one scale: a ruler, not a bill.
  • Count each call once. One reply can fill several log lines, so replies are counted by their ID.
  • One question per script. Each of six short scripts prints one table, so each answer can be checked on its own.
  • Read-only and local. Nothing to install, and nothing leaves the computer.
  • Guesses written down. Where a script has to guess, the rule is written down and adjustable, so every figure traces back to it.

How it was tested

  • Used for a real weekly spending review, then kept as reusable tools.
  • The findings became rules in claude-code-token-guard, aimed at the heavy helper type and the stretches with nobody typing.
  • Each new rule was checked by the next week’s scan, so the scripts that found a leak showed it was closed.

Limits

  • Reads Claude Code’s own log format, which can change with new versions.
  • Free to reuse (MIT license); not made or endorsed by Anthropic, the maker of Claude.
