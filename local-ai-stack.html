The problem

Everything stays on one MacBook Pro with 64 GB of memory: the AI model, the chat history, the tools and the search engine all run there.

Installing the pieces is easy. Making them work together on one laptop is the real job: tools the AI can actually use, parts that survive crashes and log-outs, and an AI fast enough for daily use. All while the model, which uses up to about 42 GB of memory, shares the laptop with everything else.

Decisions I made

  • Reachable only from this computer, and checked. Every part accepts connections only from the laptop itself, and the tool door needs a key, so nothing on the network can reach the AI or its tools.
  • A watchdog, because programs crash. At login and every 60 seconds, a starter script checks each part, starts whatever is down, in the right order, and is safe to run again and again. So the setup recovers from crashes and log-outs on its own.
  • Limit what the tools can touch. The file tool sees four folders, not all my files. The tools that run commands or drive a web browser are off unless turned on for one chat.
  • Read the logs to find the stall. The root cause: long chats in the chat window (about 190k tokens) were re-reading about 188k tokens before every tool step, 21 to 25 minutes each time. The logs showed a different app, a text-only coding assistant, lets the AI keep its earlier reading instead of starting over, so I moved long jobs there.
  • Make a silent failure loud. A built-in limit quietly threw away any tool request over 2,048 tokens, so the AI could seem to write files that never existed. The starter script raises that limit to the most the AI can hold.

How it was tested

  • Speed, measured on the laptop. 13.7 tokens per second normally, against 32 to 37.5 when guessing 3 ahead. Each extra step ahead was faster (22.9 at 1, 28.4 at 2).
  • Idle against real use. A typical 23.4 tokens per second in use, against 37.5 idle.
  • Memory, measured. The model uses up to about 42 GB in tests, and one large reply reached 62.6 GB, so everything else was planned around what was left.
  • Network openings, checked. A list of open connections caught the one part that was open to the network. The fix locked it to this computer, with one starter per part.

Limits

  • A written-up setup and step-by-step guide for a Mac, not a one-click installer.
  • The risk: the tool that runs commands has no list of allowed or banned commands, so it stays off unless turned on for a chat.
