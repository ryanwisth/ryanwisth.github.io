AI tools · safe limits when nobody is watching

Long AI jobs that check the bill first

A small tool that hands Claude, an AI assistant, a long job written out as instructions. It checks which account pays, caps the spending and the number of steps, and runs the job in fresh rounds until a “done” file appears.

Problem
Long AI jobs are easier to hand off as written instructions than as a live chat. Running them with nobody watching raises three questions: which account pays, how to stop a run that goes over budget, and how to continue a job that does not finish in one round.
Result
Ran real jobs of several rounds in October 2026, paid from my subscription by default since 2026-10-25. Every run confirms who pays before any work. Each round is capped at $20 by default. Rounds repeat until the “done” file appears, and the first failed round stops everything, with 0 retries.

The problem

Claude can be paid for two ways: a pay-per-use key, billed to that key’s account, or a subscription. If a key happens to be set up, it quietly wins over the subscription, so a run with nobody watching could bill the wrong account. The tool closes that gap: the account the AI reports must match the --auth setting, or the run stops with no work done.

Decisions I made

  • Who pays is checked, not assumed. The tool stops before the AI does anything if the reported account does not match the setting.
  • Use the built-in budget. Claude’s toolkit reports the cost only at the very end, so my own running total could not stop a run in time.
  • Fresh rounds, not one long chat. A new round that reads short progress notes costs less than carrying the whole conversation along.
  • Stop on the first failure. A round that crashed or hit a limit needs a person to look before more money is spent, so nothing is retried.
  • My standing rules still apply. The tool loads my usual settings, so the same rules govern every run, even unwatched.
  • Spend nothing on a typo. The command is checked before any round starts.

How it was tested

  • The exact account label was confirmed in a live test with the smallest AI model.
  • The who-pays check, the settings, a fresh run and a restart were tested with the smallest model before the first real job.

Limits

  • By default the AI acts without asking first, so point it at a folder it is allowed to change.
  • Stopping a round by hand part-way can leave that folder half-edited.
