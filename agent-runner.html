Guardrails for unattended AI work

Long agent jobs with the bill checked first

A small command-line runner that sends a written brief to Claude through the Claude Agent SDK, with explicit auth, budget and turn guards, and loops fresh passes until the brief's done file appears.

Problem
Long agent jobs are easier to hand off as a written brief than as a live chat. Running them unattended raises three practical questions: which account pays, how to stop a run that goes over budget, and how to continue a job that does not finish in one pass.
Result
Working, and used for real multi-pass jobs in October 2026. The subscription login became the loop's default on 2026-10-25.

The problem

A run authenticated with an API key bills that key's account; a run on the subscription login draws on the subscription instead. If an API key happens to be set, it silently wins over the login.

Decisions I made

  • Who pays is checked, not assumed. The runner aborts before the first tool call if the key source the session itself reports does not match.
  • Use the built-in budget rather than counting cost by hand. The SDK reports cost only in its final result message, so a hand-rolled running total could not stop a run in time.
  • Fresh passes over one long session. A new pass that reads short progress notes is cheaper than dragging a full transcript along.
  • Stop on the first failure. A pass that crashed or hit a cap usually needs a person to look before more money is spent, so the loop does not retry.
  • Written rules still apply. The runner loads user and project settings, so the operator's standing rules apply to unattended runs too.
  • Spend nothing on a bad command. The loop validates its arguments before spending anything.

How it was verified

  • The exact key-source string was found by a live test with the smallest model rather than guessed.
  • The auth guard, settings loading, and a fresh run plus a resume were tested with the smallest model before the first real brief.

Honest limits

  • No automated tests.
  • Stopping a pass by hand part-way can leave the working folder mid-edit.
  • By default the agent runs tools without asking, so the runner should be pointed at a folder it is allowed to change.
