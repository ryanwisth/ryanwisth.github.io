The problem

Claude can be paid for two ways: a pay-per-use key or a subscription. If a key happens to be set up, it quietly wins over the subscription, so an unwatched run could bill the wrong account.

Decisions I made

  • Who pays is checked, not assumed. A mismatched account stops the run before the AI does anything.
  • Use the built-in budget. The cost is reported only at the end, too late for a running total to stop a run.
  • Fresh rounds, not one long chat. Short progress notes cost less than carrying the whole conversation.
  • Stop on the first failure. A person looks before more money is spent.
  • Standing rules still apply. Every run loads the usual settings, even unwatched.
  • Spend nothing on a typo. The command is checked before any round starts.

How it was tested

  • The who-pays check, confirmed live with the smallest AI model.
  • Settings, a fresh run and a restart, tested before the first real job.

Limits

  • The AI acts without asking first, so point it at a folder it may change.
  • Stopping a round by hand can leave that folder half-edited.
