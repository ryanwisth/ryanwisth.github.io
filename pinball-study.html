A research tool that converts pinball table designs into one format, measures their shape, plays them with simulated players at four skill levels, and tests whether any of that predicts how much people enjoy a table. My part: the study rules and the checks. AI wrote the code and ran the experiments.

The problem

The main risk in a study like this is to try many measures and report the ones that happen to fit. This study fixed its tests and verdicts in advance, so the result could not be bent afterward.

Decisions I made

  • Predictions before results. Designers’ rules of thumb were written down, each with the direction it predicted, a fixed test and a fixed rule for the verdict. Then they were locked with a digital fingerprint, before any measure was compared with a rating.
  • One shared board format. The simulator never sees an original file, so a new design can be measured exactly like a converted commercial table.
  • Borrow the physics, do not invent it. A flipper tuned by hand was replaced with the flipper from an established pinball simulator.
  • Year and maker always counted. Every model includes them, so a table’s era and brand are not mistaken for “fun”.
  • Trust only what holds up. The expert simulated player did not reliably beat the medium-skill one, so every prediction uses the medium-skill player.

How it was tested

  • Every rating model was judged the same way: each table was predicted by a model that had not seen it, and the result was compared with simply guessing the average.
  • Each prediction was tested with error ranges (bootstrap intervals) on two separate measures of success: public rating and how many tables were made.
  • The fingerprints of the prediction files are stored with the results, so any later edit shows.

Limits

  • The finding: ratings mostly reward theme, license, how deep the game’s rules go, sound and software, which a 2D simulator cannot see.
  • The published prediction files had a few sentences and labels removed that did not change their meaning, so they no longer match the fingerprints recorded during the study.
