Research honest enough to fail

A study built so it could fail

A research tool that converts pinball table layouts, measures their geometry, plays them with simulated players at four skill levels, and tests whether any of that predicts how much people enjoy a table.

Problem
The goal was to score an original table design before anyone had played it: learn what separates well-rated tables from the rest, then apply that to the new design.
Result
The hypothesis failed. The best model's error was 0.425 against 0.448 for guessing the mean, and of the 9 rules, none passed as predicted.

The problem

The easy trap in a study like this is to try many measures and report the ones that happen to fit.

Decisions I made

  • Hypotheses before results. Designer rules of thumb were written down with predicted directions, a fixed test and a fixed verdict rule, then hashed, before any measure was compared with a rating.
  • One common board format. The simulator never sees a source file, so an original design can be measured exactly like a converted commercial table.
  • Port the physics, do not invent it. A hand-tuned flipper was replaced by a port of an established simulator's flipper model.
  • Controls in every model. Year and maker are always included, so era and brand are not mistaken for "fun".
  • Trust only what holds up. The expert bot did not reliably beat the intermediate one, so every hypothesis uses the intermediate bot.

How it was verified

  • Every rating model was judged by leave-one-out cross-validation against the simple baseline of predicting the mean.
  • Each hypothesis was tested with bootstrap intervals on two separate measures of success: public rating and production run.
  • The hashes of the hypothesis files are stored with the results, so an edit after the fact shows.

Honest limits

  • The scorer is not a usable fun predictor, and nothing in the project claims it is.
  • The best reading is that ratings mostly reward theme, licence, rules depth, sound and code, which a 2D simulator cannot see.
  • The design-check use of the simulator was not built out.
  • The published hypothesis files had a few non-substantive sentences and labels removed, so they no longer match the hashes recorded during the study.
